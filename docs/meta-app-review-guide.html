2 공통 제출 노트 (Server-to-Server App Description)

모든 권한에 공통으로 사용하는 서버 간 앱 설명입니다.

PolarAD Report is a server-to-server B2B marketing analytics platform. It runs as a backend service (Node.js + Next.js) that fetches Meta advertising data via the Marketing API and displays it on a private dashboard for our agency's clients.

How it works:
1. A System User token (Long-Lived Token) is stored securely on our server.
2. A scheduled Node.js script calls the Meta Marketing API daily to collect ad performance data (impressions, clicks, spend, conversions).
3. The collected data is stored in our database (Supabase) and displayed on a password-protected dashboard at https://report.polarad.co.kr.
4. Only authorized agency staff and clients can access the dashboard.

There is NO client-side Facebook Login flow. All API calls are made server-to-server using the System User token. End users never interact with Facebook Login or OAuth.

캡션 내레이션 (영어)

"ads_read is our core permission. We use it to fetch ad account insights — impressions, clicks, spend, and conversions — from the Marketing API. This data powers our KPI cards, charts, and weekly/monthly reports on the client dashboard."

제출 노트 (Submission Note)

ads_read is the core permission for our application. We use it to retrieve advertising performance data from the Meta Marketing API. This is a server-to-server application.

Specific API calls:
- GET /me/adaccounts — list all ad accounts accessible to our System User
- GET /act_{ad-account-id}/insights — retrieve daily performance metrics (impressions, clicks, spend, conversions, video views)
- GET /act_{ad-account-id}/campaigns — list campaigns for breakdown analysis

A backend Node.js script runs daily to fetch this data using a System User token. The data is stored in our database and displayed on a password-protected dashboard (https://report.polarad.co.kr) where agency clients can view KPI cards, performance charts, and weekly/monthly reports.

No end-user Facebook Login is involved. All API calls use a long-lived System User token.

캡션 내레이션 (영어)

"ads_management allows our platform to manage campaign status. Here I'm toggling a campaign from ACTIVE to PAUSED using the API. Agency staff use this feature to quickly pause or activate campaigns directly from our dashboard."

제출 노트 (Submission Note)

We use ads_management to allow agency staff to manage campaign status (pause/activate) directly from our dashboard. This is a server-to-server application.

Specific API calls:
- GET /act_{ad-account-id}/campaigns?fields=name,status,objective — list campaigns with their current status
- POST /{campaign-id} with status=PAUSED or status=ACTIVE — toggle campaign on/off

Agency staff can view all campaigns on the /meta/ads-management page and toggle their status with a single click. This avoids the need to switch to Facebook Ads Manager for simple campaign management tasks.

No end-user Facebook Login is involved. All API calls use a long-lived System User token.
