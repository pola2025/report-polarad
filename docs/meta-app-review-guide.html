🎯 1. 서비스 개요

서비스명

PolarAD Report

서비스 URL

https://report.polarad.co.kr

회사명

폴라애드 (PolarAD)

회사 웹사이트

https://polarad.co.kr

서비스 설명

PolarAD Report는 Meta(Facebook/Instagram) 광고 데이터를 수집하여 클라이언트에게 주간/월간 광고 성과 리포트를 제공하는 B2B 마케팅 분석 서비스입니다. 광고주는 대시보드를 통해 캠페인 성과, 비용, ROI 등을 실시간으로 확인할 수 있습니다.

🔐 2. 필요 권한 및 사용 목적

ads_read

광고 데이터 읽기

필수

사용 목적:

  • 광고 계정의 캠페인, 광고 세트, 광고 데이터 조회
  • 노출수, 클릭수, 비용, 전환 등 인사이트 데이터 수집
  • 주간/월간 리포트 생성을 위한 성과 데이터 집계

API 엔드포인트 예시:

GET /act_{ad-account-id}/insights?fields=impressions,clicks,spend

ads_management

광고 관리

필수

사용 목적:

  • 광고 계정의 캠페인 목록 및 상세 정보 조회
  • 광고 세트 및 광고 크리에이티브 정보 접근
  • 캠페인별 성과 분석 및 비교

API 엔드포인트 예시:

GET /act_{ad-account-id}/campaigns?fields=name,status,objective

business_management

비즈니스 관리

필수

사용 목적:

  • 비즈니스 매니저에 연결된 광고 계정 목록 조회
  • 클라이언트별 광고 계정 매핑
  • 비즈니스 자산 접근 권한 확인

API 엔드포인트 예시:

GET /me/businesses, GET /{business-id}/owned_ad_accounts

pages_read_engagement

페이지 참여도 읽기

선택

사용 목적:

  • 광고와 연결된 Facebook 페이지 참여도 데이터 조회
  • 페이지 팬 수, 도달, 참여율 등 보조 지표 수집

🎬 4. 스크린캐스트 제작 가이드

⚠️ 중요: 스크린캐스트가 승인의 80%를 결정합니다

명확하고 간결한 비디오가 빠른 승인의 핵심입니다.

📹 비디오 요구사항

  • • 길이: 2분 이내 권장
  • • 언어: 영어 설명/자막 권장 (검토자가 외국인일 수 있음)
  • • 화질: 1080p 이상
  • • 형식: MP4, MOV

📝 녹화 스크립트

1

서비스 소개 (10초)

"This is PolarAD Report, a marketing analytics dashboard that displays Meta advertising performance data for our B2B clients."

2

대시보드 접속 (20초)

report.polarad.co.kr 접속 → 로그인 → 클라이언트 선택
"Here I'm accessing the dashboard and selecting a client account."

3

ads_read 사용 화면 (30초)

KPI 카드, 차트 등 광고 성과 데이터 표시 화면
"This data - impressions, clicks, spend, and conversions - is fetched using the ads_read permission from Meta Marketing API."

4

ads_management 사용 화면 (20초)

캠페인 목록, 캠페인별 성과 비교
"We use ads_management to retrieve campaign details and compare performance across different campaigns."

5

business_management 사용 화면 (15초)

광고 계정 목록/선택 화면
"The business_management permission allows us to list all ad accounts connected to the business."

6

리포트 생성/다운로드 (15초)

주간/월간 리포트 조회 화면
"Clients can view weekly and monthly reports generated from this data."

7

마무리 (10초)

"Thank you for reviewing our application. PolarAD Report helps marketing agencies provide transparent reporting to their clients."
