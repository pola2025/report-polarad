GA4 폼 제출 이벤트 설정 가이드

나라똔 웹사이트에 폼 제출 추적 이벤트를 설정하는 방법

목적: 웹사이트 문의 폼 제출을 GA4에서 추적하여 마케팅 퍼널 분석에 활용

진행 체크리스트

1

이벤트 코드 복사

아래 코드를 나라똔 웹사이트에 추가합니다. 기존 gtag 설정 아래에 추가하세요.

옵션 A: 모든 폼 자동 추적 (권장)

페이지 내 모든 <form> 태그의 제출을 자동으로 추적합니다.

<script>
// GA4 폼 제출 이벤트 추적 (자동)
document.addEventListener('DOMContentLoaded', function() {
  document.querySelectorAll('form').forEach(function(form) {
    form.addEventListener('submit', function(e) {
      var formName = this.getAttribute('name') || this.getAttribute('id') || 'contact_form';

      // GA4 이벤트 전송
      gtag('event', 'generate_lead', {
        'event_category': 'form',
        'event_label': formName,
        'form_name': formName,
        'page_path': window.location.pathname,
        'page_title': document.title
      });

      console.log('GA4 폼 제출 이벤트 전송:', formName);
    });
  });
});
</script>

옵션 B: 특정 폼만 추적

특정 ID를 가진 폼만 추적합니다. 폼의 ID를 확인 후 수정하세요.

<script>
// GA4 폼 제출 이벤트 추적 (특정 폼)
document.addEventListener('DOMContentLoaded', function() {
  // TODO: 아래 폼 ID를 실제 폼 ID로 변경하세요
  var formIds = ['contact-form', 'inquiry-form', 'consultation-form'];

  formIds.forEach(function(formId) {
    var form = document.getElementById(formId);
    if (form) {
      form.addEventListener('submit', function(e) {
        gtag('event', 'generate_lead', {
          'event_category': 'form',
          'event_label': formId,
          'form_name': formId,
          'page_path': window.location.pathname
        });
        console.log('GA4 폼 제출 이벤트 전송:', formId);
      });
    }
  });
});
</script>

옵션 C: AJAX 폼용 (페이지 새로고침 없는 폼)

폼 제출 시 페이지가 새로고침되지 않는 경우 사용합니다.

<script>
// GA4 AJAX 폼 제출 이벤트
function trackFormSubmit(formName) {
  gtag('event', 'generate_lead', {
    'event_category': 'form',
    'event_label': formName || 'ajax_form',
    'form_name': formName || 'ajax_form',
    'page_path': window.location.pathname
  });
  console.log('GA4 폼 제출 이벤트 전송:', formName);
}

// 사용 예시: 폼 제출 성공 콜백에서 호출
// trackFormSubmit('consultation_form');
</script>
2

웹사이트에 코드 추가

중요: 기존 gtag 코드(Google Analytics 스크립트) 아래에 추가하세요.

코드 위치:

  1. <head> 태그 내 기존 gtag 코드 찾기
  2. 기존 gtag 코드 바로 아래에 새 코드 추가
  3. 저장 후 배포

<!-- 기존 Google Analytics 코드 -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>

<!-- 여기에 폼 추적 코드 추가 -->

3

GA4 실시간 테스트

코드 추가 후 이벤트가 제대로 전송되는지 확인합니다.

테스트 방법:

  1. GA4 콘솔 접속
  2. 보고서 → 실시간 클릭
  3. 나라똔 웹사이트에서 테스트 폼 제출
  4. GA4 실시간에서 generate_lead 이벤트 확인

확인 포인트: 브라우저 개발자 도구(F12) → Console에서 "GA4 폼 제출 이벤트 전송" 메시지 확인

4

GA4에서 전환 설정

이벤트를 "전환"으로 설정하여 GA4 보고서에서 전환율을 확인할 수 있습니다.

설정 경로:

GA4 관리 → 속성 설정 → 데이터 표시 → 이벤트

전환 설정:

  1. 이벤트 목록에서 generate_lead 찾기
  2. 해당 이벤트 행의 오른쪽 "전환으로 표시" 토글 활성화
  3. 설정 완료!

참고: 이벤트가 목록에 나타나려면 최소 1회 이상 발생해야 합니다. Step 3에서 테스트 후 24시간 내 표시됩니다.

설정 완료 후

  • • GA4에서 폼 제출 이벤트가 추적됩니다
  • • 대시보드에서 "홈페이지 접수" 데이터로 활용됩니다
  • • 마케팅 퍼널 분석에서 전환율 계산이 가능해집니다
  • • 데이터가 쌓이면 (최소 7일) 상관관계 분석이 가능합니다

문제 해결

이벤트가 전송되지 않는 경우

  • 기존 gtag 코드가 있는지 확인
  • 코드가 gtag 뒤에 위치하는지 확인
  • 브라우저 콘솔에서 에러 확인

AJAX 폼인 경우

  • 옵션 C 코드 사용
  • 폼 제출 성공 콜백에서 trackFormSubmit() 호출
