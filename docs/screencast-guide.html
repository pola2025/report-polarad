Meta 앱 검수 - 스크린캐스트 촬영 가이드

각 권한별로 30초~1분 영상을 촬영하세요. Win + Alt + R로 녹화

촬영 공통 팁

  • • 천천히 진행 (검수자가 화면을 읽을 시간 필요)
  • • 마우스 커서를 중요한 요소 위에 잠시 멈추기
  • • 스크롤은 부드럽게
  • • 실제 데이터가 화면에 표시되어야 함

촬영 진행 체크리스트

1. ads_management

가장 중요
https://report.polarad.co.kr/meta/ads-management

촬영 순서 (약 45초)

  1. 페이지 로드 - 전체 화면 보여주기 (5초)
  2. "Permission Granted" 배지 영역에 마우스 올리기 (3초)
  3. 캠페인 목록 영역으로 스크롤 (5초)
  4. "Pause" 버튼 위에 마우스 올리기 (3초)
  5. Pause 버튼 클릭 → 상태가 PAUSED로 변경 확인 (5초)
  6. "Activate" 버튼 클릭 → 상태가 ACTIVE로 복원 (5초)
  7. API 예시 코드 영역 보여주기 (5초)
  8. 페이지 전체 다시 보여주기 (5초)

핵심: 사용자가 대시보드에서 직접 광고 캠페인을 켜고 끌 수 있음을 보여주세요

2. Ads Management Standard Access

1번(ads_management)과 동일한 영상을 사용하세요!
같은 영상 파일을 두 권한에 모두 업로드하면 됩니다.

3. pages_show_list

https://report.polarad.co.kr/meta/pages-show-list

촬영 순서 (약 30초)

  1. 페이지 로드 - 전체 화면 보여주기 (5초)
  2. Facebook 페이지 목록 영역 보여주기 (5초)
  3. 페이지 항목 위에 마우스 올리기 (3초)
  4. 페이지 정보 (이름, ID, 카테고리) 보여주기 (5초)
  5. API 예시 영역 보여주기 (5초)
  6. 페이지 전체 다시 보여주기 (5초)

핵심: 사용자가 관리하는 모든 Facebook 페이지 목록을 한눈에 볼 수 있음

4. business_management

https://report.polarad.co.kr/meta/business-management

촬영 순서 (약 30초)

  1. 페이지 로드 - 전체 화면 보여주기 (5초)
  2. 광고 계정 목록 영역 보여주기 (5초)
  3. 계정 정보 (이름, ID, 상태) 보여주기 (5초)
  4. 여러 계정이 있다면 스크롤 (5초)
  5. API 예시 영역 보여주기 (5초)
  6. 페이지 전체 다시 보여주기 (5초)

핵심: Business Manager에 연결된 모든 광고 계정을 조회할 수 있음

5. ads_read

https://report.polarad.co.kr/meta/ads-read

촬영 순서 (약 30초)

  1. 페이지 로드 - 전체 화면 보여주기 (5초)
  2. 광고 계정 상태 영역 보여주기 (5초)
  3. 성과 데이터 (지출, 노출, 클릭 등) 보여주기 (5초)
  4. 데이터 카드 위에 마우스 올리기 (5초)
  5. API 예시 영역 보여주기 (5초)
  6. 페이지 전체 다시 보여주기 (5초)

핵심: 광고 성과 데이터를 읽어와서 대시보드에 표시

  4. 데이터 카드 위에 마우스 올리기 (5초)
  5. API 예시 영역 보여주기 (5초)
  6. 페이지 전체 다시 보여주기 (5초)

핵심: Facebook 페이지의 참여 지표(engagement metrics)를 조회
