담당자 추가

  1. a 리드관리 페이지 필터 바 오른쪽 담당자 관리 버튼 클릭

5

리드에 담당자 배정

리드 목록에서 상세 버튼 → 상세 패널에서 담당자 드롭다운을 선택하여 배정합니다.

실제 화면 — 리드 상세 패널 (상태 변경, 담당자 배정, 블랙리스트) 클릭하면 확대

배정 후 담당자에게

  • - 개인 포털에서 배정된 리드만 표시
  • - 상태 변경/메모 작성 가능
  • - 계약 완료 시 텔레그램 알림

관리자 대시보드에서

  • - 담당자별 처리 현황 통계
  • - 상태별 분포 한눈에 파악
  • - 담당자 필터로 빠른 검색

? 자주 묻는 질문

담당자가 텔레그램이 없으면요?
텔레그램 설치가 필수입니다. iOS/Android 모두 무료 앱입니다. 인증과 알림 모두 텔레그램을 통해 이루어집니다.
담당자를 삭제하면 배정된 리드는?
리드 데이터는 유지됩니다. 담당자명이 그대로 표시되지만 해당 담당자의 포털 접근이 불가해집니다. 리드를 다른 담당자에게 재배정해주세요.
담당자가 비밀번호를 잊어버리면?
비밀번호가 없습니다! 이메일 + 텔레그램 OTP 방식이라 별도 비밀번호 관리가 필요 없습니다. 이메일만 기억하면 됩니다.

A 용어 정리

슬러그담당자 포털 URL에 사용되는 영문 약자 코드 (자동생성)
활성화 토큰텔레그램 봇 연결에 사용되는 1회용 토큰 (자동생성)
OTP텔레그램으로 전송되는 6자리 일회용 인증코드 (5분 유효)
포털담당자 전용 리드관리 페이지 (배정된 리드만 표시)
블랙리스트스팸/중복 리드를 목록에서 제외하는 기능
